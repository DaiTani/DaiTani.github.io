AI杂谈 | BioEmu 2026：当蛋白从一张静态图变成一个构象集合

过去十年，AI 在结构生物学里最成功的故事是”预测一张图”：给一条氨基酸序列，模型吐出一个三维结构。这一招太好用了，以至于我们差点忘了，真实蛋白根本不是一座雕塑，而是一团永不停止的呼吸。

蛋白在溶液里从来不静止，它的”真实形状”是一整片构象地形，而不是一个点。

一、静态结构图的盲区

AlphaFold2、ESMFold 这类模型把结构预测的精度推到了实验可比的高度，但它们的输出本质上仍是一次采样：一个”最可能”的构象。可问题在于，很多药物机制恰恰发生在单张结构图看不到的地方：

  • 铰链呼吸（hinge breathing）：激酶活性环的微小开合，决定了抑制剂能不能结合。
  • 局部解折叠：一个十几个残基的环区在 apo 态是松的，在 holo 态才收紧。
  • 隐匿口袋（cryptic pocket）：结合位点在没有配体时根本不存在，需要蛋白”打开”一条缝才显形——这是下一代靶点发现的核心方向，也是单结构方法几乎必然漏掉的地方。

这些现象的共同点是：它们是分布，不是结构。要刻画一个分布，理论上最直接的做法是分子动力学（MD）模拟——让原子按物理规律跑上几毫秒，采出一整条轨迹。但 MD 的代价极其高昂：单个蛋白体系跑毫秒级往往需要 GPU 年，而真实细胞里重要的构象转变常常还要更久。

BioEmu 要做的，就是把这一步”摊销”掉。

把构象空间当成一片有高低起伏的地形，”一个蛋白”其实是这片地形上的一个分布。

二、BioEmu 到底做了什么

BioEmu（Biomolecular Emulator）出自微软研究院 AI for Science 团队，论文《Scalable emulation of protein equilibrium ensembles with generative deep learning》发表于 Science（PubMed: 40638710），模型与训练数据随后在 GitHub / Hugging Face（microsoft/bioemu）开源。

核心思路

它不预测”一个结构”，而是采样蛋白的玻尔兹曼平衡分布：直接从一个 SE(3) 等变的扩散模型（score-based denoiser）中，生成成千上万个统计上相互独立的构象。

维度 传统结构预测 分子动力学 BioEmu
输出 单个构象 时间轨迹 平衡构象集合
时间尺度 — 毫秒级 复用已有 MD 数据
典型成本 分钟 GPU 年 GPU 小时（单卡 H100）
是否含动力学信息 否 是 否（只给平衡分布）

训练数据有多厚

BioEmu 1.1 分三个阶段训练，数据规模是它区别于”图像类生成模型”的地方：

  • 超过 200 毫秒的分子动力学模拟数据，覆盖数千个蛋白体系、上万个突变体；
  • PDB 静态结构；
  • 50 万条实验测量的蛋白稳定性数据（稳定性 = 折叠态与解折叠态的概率比，是最容易被实验测量的热力学量）。

同时它内联了 ColabFold / AlphaFold2 的 MSA 嵌入作为条件输入，因此直接吃氨基酸序列。

官方给出的量化结果

  • 单张 H100 上，几分钟生成 1 万个以上结构多样的构象，每 GPU 小时可产数千个；
  • 相对自由能误差 约 1 kcal/mol（与毫秒级 MD 和实验稳定性数据对比）；
  • 构象变化覆盖率：结构域运动 85%，局部解折叠 72%/74%（分别对应局部折叠态与局部解折叠态），隐匿口袋 apo 态 49%、holo 态 85%；
  • 稳定性预测：误差 < 1 kcal/mol，大规模测试集相关性 > 0.6，且对单突变与双突变的稳定性变化同样有效。

从单一构象走向构象空间，是这一代模型的核心转变。

三、冷静的反证：独立评估怎么说

模型自己发的数据不能只听模型自己说。Journal of Chemical Information and Modeling（JCIM）刊出的一篇独立工作《Accelerated Sampling of Protein Dynamics Using BioEmu-Augmented Molecular Simulation》提供了难得的第三方视角。

它的做法是：用 BioEmu 生成的构象集合作为分子模拟的初始状态，再用统计力学重加权把构象分布恢复成玻尔兹曼权重，然后看能否重现实验观测到的构象变异。

结论是分裂的：

体系 结果
BRAF 激酶 成功采样到功能相关的亚稳态，能捕捉突变引起的状态占比迁移
CDK2 激酶 成功，优于 rMSA-AF2 播种的模拟
GlyT1（甘氨酸转运体） 失败，未能复现实验观测到的构象异质性
PlmII（质子泵II） 失败，侧链构象异质性没被复现

作者还点出一个要害：生成模型能给出多样的构象，但哪些构象在生理条件下真的被占据、占比多少，是另一回事。换句话说，”能采样到”和”能定量”之间，还隔着一次物理重加权。

这类结果恰恰说明问题所在：BioEmu 的短板集中在侧链异质性上——而侧链又恰恰是配体识别的直接参与者。

四、隐匿口袋：真正的价值点

从药物发现的角度看，BioEmu 最有说服力的能力是隐匿口袋的预测成功率提升。

传统做法是”对 apo 结构做虚拟筛选”，然后在真实实验中扑空——因为口袋本身需要蛋白自己张开。BioEmu 的做法是：先采样出成千上万个构象，其中一部分已经处于口袋张开的状态，在这些构象上做对接，就能看到静态结构里根本不存在的结合位点。

这也是为什么它和 Chai Discovery 的 Chai-1 这类”结构生成 + 采样”流水线天然契合：前者提供 ensemble，后者提供以 ensemble 为条件的结构/相互作用预测。BioEmu 官方也把与 OpenMM 的集成作为标配，使其生成的集合可以无缝接回经典 MD 流程做后续精修。

五、它不能做什么

把这篇文章写成吹捧文对谁都没好处。BioEmu 的边界相当清楚：

  1. 不建模动力学。它给的是平衡分布的快照，不是时间轴。你无法从采样结果里读出”转变速率”或”过渡态路径”。
  2. 不考虑配体、膜、环境条件。温度、pH、配体结合都会改变平衡分布，而它对这些没有显式建模。
  3. 受训练数据覆盖度限制。对训练分布之外的蛋白或突变，泛化能力会明显下降——这在生成模型里是常态，不是 BioEmu 独有的问题。
  4. 定量仍需物理兜底。第三方评估显示，直接把采样结果当作物理真相是不够的，需要统计力学重加权。

把 GPU 年压成 GPU 小时之后，真正的瓶颈从”算力”转移到了”如何为采样结果做物理赋权”。

六、结语

BioEmu 真正的贡献，或许不是某一个数字，而是把结构生物学的问题定义从”预测结构”改写成了”预测分布”。一旦接受这个定义，很多原本属于物理学家和化学家的昂贵工作，就有机会被摊销成一次数据生成 + 一次 GPU 推理。

但它也把新的责任推给了使用者：你会拿到一堆看起来合理、彼此多样的构象，然后必须自己判断——哪一个是真的？占比多少？哪一个能拿去对接？

蛋白从来没有一张”正确”的结构图，它只有一片地形。BioEmu 第一次让这片地形可以被廉价地采样出来；至于要不要相信这片地形，还是得回到实验台前。
