前言

2026年9月10日，一则来自北京协和医院与上海市肺科医院的消息，在全球生物医药圈引发震动——英矽智能自主研发的特发性肺纤维化（IPF）新药 Rentoserib 完成了Ⅲ期临床首例患者入组给药。这不是一款普通的新药：它的靶点由AI发现，分子结构由AI设计，从靶点验证到进入后期临床仅用了不到四年时间——传统制药模式下，这一过程通常需要十年以上。

这标志着，AI制药不再只是”PPT里的愿景”或”实验室里的演示”，而是真正意义上经受了临床验证的产业力量。

2026年，是AI制药从概念验证走向规模化落地的关键之年。本文将围绕这一转折，系统梳理AI制药的最新技术突破、重要玩家动态、临床进展与未来挑战。

一、大模型公司集体杀入生物医药：2026的新格局

过去一年，AI领域的头部公司不再满足于”通用大模型”的竞争，而是将触角伸向生物医药这一垂直赛道。这背后有着清晰的商业逻辑：制药市场的规模高达万亿美元，且药物研发周期长、效率瓶颈明确，AI的介入可以带来真实的效率跃升。

1.1 OpenAI：GPT-Rosalind开启靶点推理新时代

2026年4月，OpenAI与诺和诺德（Novo Nordisk）建立战略合作伙伴关系，并同步推出面向生物医药复杂机理推理的专用模型 GPT-Rosalind。这款模型得名于诺贝尔化学奖得主罗莎琳德·富兰克林（Rosalind Franklin），其定位是加速疾病靶标分析与筛选。

GPT-Rosalind的核心能力在于：基于生物医学文献、蛋白质相互作用网络、基因表达谱数据，进行多跳推理，从而帮助研究人员从海量生物学数据中快速定位具有成药潜力的靶点。这解决了传统靶点发现过程中”信息过载但洞察匮乏”的核心痛点。

1.2 英伟达：BioNeMo Agent Toolkit连接AI与制药全流程

英伟达在生物医药AI领域的布局由来已久，但2026年6月正式推出的 BioNeMo Agent Toolkit 代表了其策略的质变——从提供底层算力，转向提供上层智能体协作框架。

BioNeMo Agent Toolkit已接入礼来（Lilly）、达索系统（Dassault Systèmes）、薛定谔（Schrödinger）等超过50家行业龙头。更重量级的是，2026年1月英伟达宣布与礼来达成5年10亿美元的战略合作，共建联合AI创新实验室，这是AI基础设施公司与顶级药企之间有史以来最大规模的单项合作。

1.3 Isomorphic Labs：21亿美元B轮刷新行业融资记录

谷歌DeepMind于2021年拆分出的AI制药公司Isomorphic Labs，在2026年5月完成了高达21亿美元的B轮融资，一举刷新行业纪录。其自主研发的新一代设计引擎 IsoDDE（Isomorphic Deep Drug Engine）已全面赋能与辉瑞、诺华的心血管及肿瘤药物合作项目。

IsoDDE的核心创新在于：将AlphaFold系列积累的蛋白质结构预测能力，与基于强化学习的分子生成能力深度整合，实现了从靶点结构分析到候选分子设计的一体化工作流。

1.4 Meta：Muse Wonder的多领域渗透

2026年10月，Meta推出全新模型家族 Muse Wonder。独立评测显示，其在智能体知识工作和科学推理任务上已跻身第一梯队，与OpenAI、Anthropic、Google形成”前沿四强”格局。Muse Wonder的Active Focus与Active Memory功能为个人AI Agent提供了新的技术范式，其在生物医药文献分析、多组学数据整合等场景中的应用潜力正在被持续探索。

二、技术突破：从”暴力堆砌算力”到”垂直科学智能”

2.1 小模型打败大模型：26亿参数超越千亿参数

长期以来，AI行业存在一种”唯参数量论”的叙事：模型越大，能力越强。然而，2026年英矽智能与Liquid AI联合发布的 LFM-2-2.6B-MMAI 模型，彻底颠覆了这一认知。

这款仅26亿参数的轻量化科学基础模型，在药物发现的多项基准测试中，性能超越了参数量十倍于自身的通用大模型。其核心创新在于”多任务化学模型”架构——单个模型即可覆盖ADMET成药性预测、多参数分子优化、蛋白口袋评估、靶点验证以及逆合成路线设计等200余项研发任务。

这一成果具有深远的行业意义：它证明在药物发现这类专业门槛极高的领域，领域专用模型（Domain-Specific Model） 远比通用大模型更高效。通用大模型需要消耗大量算力去”蒸馏”通用知识，而专用模型从一开始就将全部参数用于学习化学和生物学规律，效率差距由此拉开。

英矽智能的评估显示，在70余个基准任务中，其专用模型均达到了行业顶尖SOTA水平。

2.2 零样本抗体设计：从0.1%到16%的效率飞跃

抗体药物是现代生物医药的重要组成部分，但传统抗体设计高度依赖专家经验和大量实验试错。2026年，一项来自多机构协作的突破性成果引发了业界关注：Chai-2模型实现了真正的”零样本”抗体设计。

面对一个从未见过的靶点蛋白，该模型能直接根据其三维结构，从头生成具有高亲和力的全新抗体序列，将成功率从不足0.1%提升至16%，效率提升高达百倍。

与此同时，OpenFold3的发布为行业提供了开源的蛋白质-配体及抗体-抗原复合物共折叠工具，大幅降低了行业技术门槛，使更多研究机构能够参与到尖端抗体设计中。

2.3 结构生成与亲和力预测的联合建模

2026年7月，一项发表于《自然·通讯》的研究引发了广泛关注。由多个研究机构联合发布的 FLOWR.ROOT模型，首次将口袋感知三维配体生成、多终点结合亲和力预测整合至同一架构。

该模型依托数十亿配体构象和数百万蛋白-配体复合物数据进行大规模预训练，支持从头分子生成（de novo generation）、骨架跃迁（scaffold hopping）、片段生长（fragment growing）等多种药物设计场景，已在激酶选择性等真实研发项目中完成验证。

借助生成式AI与强化学习开展分子生成与合成路径规划，新药研发早期阶段平均周期由传统方案的约24个月压缩至8个月，效率提升约三倍。

三、临床进展：从”AI设计”到”AI制药”有多远？

3.1 首批AI药物的临床成绩单

随着首批AI设计药物进入临床试验，行业进入了一个冷静审视期。数据显示，AI赋能药物的临床成功率呈现出明显的”前高后低”特征：

  • I期临床：AI发现分子的成功率可达80%90%，远高于传统药物研发的40%65%
  • II期临床：成功率回落至约40%，与传统研发的~37%无统计学差异
  • III期临床：目前进入III期的AI药物仅有屈指可数

根据动脉网对63家企业、117条AI药物临床管线的统计：60条完成I期临床，仅8条完成II期，3条进入III期。这一数字提醒我们：AI可以高效地发现分子，但分子的成药性与临床安全性，仍是AI无法绕过的刚性约束。

3.2 代表性管线：曙光初现

尽管整体临床成功率尚待提升，部分管线的进展已足够令人振奋：

药物 公司 适应症 进展 亮点
Rentoserib 英矽智能 特发性肺纤维化 III期 全球首个AI全流程设计药物
MDR-001 德睿智药 代谢疾病 III期 IIb期24周最高减重10.3%
RLY-2608 Relay Therapeutics 乳腺癌 II期 中位PFS达11.1个月

Rentoserib 的III期启动尤为里程碑式——它不仅是首个由AI完成靶点发现与分子设计的药物进入后期临床，更标志着”AI制药”从概念走向了真实的临床证据生产。

3.3 英矽智能：港股首家AI制药全面盈利

2026年8月，英矽智能发布半年度财务业绩：实现营收1.063亿美元，同比激增287.2%，毛利率高达90.3%，成为港股首家实现半年度全面盈利的AI制药公司。年内对外公布的授权合作总价值已近70亿美元，合作伙伴覆盖礼来、SK生物制药、武田制药及施维雅等全球头部药企。

英矽智能的盈利路径清晰地展示了AI制药的一种可行商业模式：以AI平台能力对外赋能（MaaS），同时保留自研管线。两条腿走路，既能通过合作收入保持现金流，又能保留核心管线的长期价值。

四、AI Agent：药物研发的”自动驾驶”时刻

4.1 智能体架构：从单点工具到科研助手

如果说2024-2025年的AI制药还停留在”AI辅助单一步骤”的阶段，那么2026年的标志性趋势，就是AI Agent（人工智能智能体） 开始全面渗透药物研发的全流程。

英矽智能在2026年秋季发布的Pharma.AI平台升级中，全面部署了模型上下文协议（MCP）服务器，使自主AI Agent能够直接无缝连接至其生物学、化学及大分子生物药引擎。典型应用场景包括：

  • PandaOmics Agent：研究人员用自然语言提出生物学问题，智能体自动检索文献、分析组学数据、生成带证据的靶点分析报告
  • Generative Biologics Agent：自动化抗体设计与筛选工作流，从靶点分析到候选分子生成，全流程无需人工逐步操作
  • Chemistry42 Agent：整合分子生成、性质评估、逆合成分析的多步骤工作流协调

这种”智能体层（Agentic Layer）”的引入，意味着药物研发正从”人指挥AI工具”转向”AI自主推进科研流程”。英矽智能称之为制药的”智驾新纪元”——就像从手动驾驶辅助升级到自动驾驶。

4.2 强化学习智能体：改变科学工作流

多机构正在部署的另一个重要方向，是将带可验证奖励的强化学习（RLVR） 应用于科学智能体训练。

与传统依赖专家演示数据集的监督学习不同，RLVR通过代码执行、实验验证等客观奖励信号来训练智能体。经RLVR训练的智能体，能够将文献综述、假设生成、实验设计、数据分析和结果总结串联起来，自主完成多步骤研究任务。

在经过RLVR训练后，智能体能够将预训练阶段习得的技能组合成新的工作流程，实现特定科学目标——这是单纯的监督学习无法实现的能力。当然，研究人员也坦承：当前系统擅长执行预定义实验方案，但在初始假设失败时的创造性问题解决能力仍然有限，人类科学家在战略决策中仍不可或缺。

4.3 自动驾驶实验室：24小时不间断做实验

“干湿闭环”（Dry Lab-Wet Lab闭环）是2026年AI制药领域最受关注的基础设施概念之一。

传统药物发现流程中，AI设计的分子需要人工排队送入实验室进行合成和测试，实验验证往往成为整个流程的瓶颈。自动驾驶实验室通过机器人设施，实现24小时不间断的”设计-合成-测试-学习”循环：

  • AI在虚拟环境设计候选分子
  • 机器人自动执行化学合成
  • 自动化分析设备快速反馈实验结果
  • AI根据反馈更新分子设计策略

这种闭环将药物发现早期阶段的迭代周期从月级别压缩至天级别，是AI制药走向工业化的关键基础设施。

五、监管与挑战：在高速发展中保持清醒

5.1 监管合规同步前置

随着AI药物进入临床和商业化阶段，全球监管机构也在加速完善相关框架：

  • FDA 已开始要求AI药物申报中包含模型溯源和可解释性文档，AI设计过程不再是”黑箱”
  • EMA 正在制定AI在药物警戒中的使用指南
  • 中国国家药品监督管理局（NMPA）也在积极探索AI辅助药物审评的路径

行业趋势是：监管合规不再是药物开发末期的”打勾”环节，而是从项目启动时就被纳入考量。模型的可解释性、训练数据的来源、预测结果的置信度——这些都成为监管审查的必备材料。

5.2 数据质量仍是最大瓶颈

尽管AI模型能力在快速提升，但一个根本性的障碍始终没有根本改变：高质量标注数据的稀缺性。

调查显示，68%的科技高管认为数据质量低下和治理不善是AI项目失败的主要原因。药物发现需要的是具有生物学、药理学和临床注释的高质量数据集，这类数据获取成本高、隐私保护限制多、跨机构标准化程度低。

联邦学习正在成为解决这一问题的潜在路径：通过隐私保护架构，让不同机构的专有数据能够在不直接共享原始数据的前提下，参与联合模型训练。但跨机构数据标准化、知识产权归属和计算基础设施需求，仍是尚待解决的问题。

5.3 AI距离”改变整个研发周期”还有多远？

需要冷静指出的是：当前AI在药物发现阶段的效率提升是真实的，但这种提升尚未根本性地改变整个制药研发的经济模型。

“将药物研发速度提升10倍”的说法，在过去几年中被频繁引用，但这个说法混淆了临床前阶段加速与整体研发周期的概念。临床试验的入组、随访、监管审评等环节的固有周期，AI无法绕过——生物学特性和临床规律是刚性的。

AI制药的真正价值，更准确地说，是：在十年研发周期中，将最具风险、最耗时的早期发现阶段从2-3年压缩到6-12个月，同时提高分子的质量和成药性概率。这是一个巨大而有意义的进步，但不是一场革命性的颠覆。

六、未来展望：2027年之后的AI制药

展望未来，AI制药的发展将呈现几个明确趋势：

第一，垂直领域专用模型将继续替代通用模型，在各自细分领域内更高效地解决问题。小模型打败大模型的案例会越来越多。

第二，多智能体协作将成为主流科研范式。未来的药物研发团队，可能由数十个专业化AI Agent组成，每个Agent负责特定环节（靶点发现、分子设计、成药性预测、临床数据分析），它们通过标准协议通信、协同工作，人类科学家则转变为战略决策者和质量控制者。

第三，首个AI设计药物的获批时间窗口，目前预计在2027-2028年。Rentoserib的III期数据预计2029年读出，如果结果积极，将是真正意义上的历史性时刻。

第四，数据基础设施的重要性将超越算法本身。谁拥有高质量、标准化的生物医药数据，谁就拥有AI制药时代的核心竞争力。数据壁垒的构建，将是下一阶段企业竞争的关键战场。

结语

2026年的AI制药行业，正处于一个微妙而激动人心的时刻：技术能力已经充分验证，商业模式初步跑通，但真正的临床大考才刚刚开始。

Rentoserib进入III期临床，是中国AI制药企业的骄傲时刻，也是一个新的起点。从”AI设计出一个分子”到”AI帮助研发出一款真正的药物”，中间隔着生物学的不确定性、临床试验的严谨性和监管的科学性。这些都不是算力能够解决的问题，需要整个行业以更长远的耐心去走完这条路。

AI制药的黄金时代，正在以一种比预期更务实的方式到来。好戏，才刚刚开始。
